# 逆風工坊

以互動 3D 模型展示逆風前行車的骨架、兩次轉向傳動與組裝分組。

## 網站功能

- 拖曳旋轉、縮放與風力傳動示意。
- 整組拆解與還原。
- 點選底盤、支架或垂直傳動組可聚焦，其他零件變半透明；聚焦後才顯示組件名稱。
- 原始 STL 對照及完整展示模型匯出。

## 本機執行

在儲存庫根目錄執行：

```sh
python3 -m http.server 8765
```

以瀏覽器開啟 http://localhost:8765/ 。請透過 HTTP 開啟，直接雙擊 HTML 可能無法載入 JavaScript 模組。

## GitHub Pages

網站由 `main` 分支的根目錄發布。修改並推送檔案後，GitHub Pages 會重新部署。

所有網站資源使用相對路徑，可在 GitHub Pages 的專案網址下運作，無須建置。

## 模型說明

骨架依提供的組裝 STL 修正貼合面。垂直傳動預組件包含軸、兩個藍色軸座與齒輪，拆解時整組移開；水平軸留在 n 形支架，輪軸齒輪固定，輪胎各自向外移開。

新增齒輪與葉片為教學展示，未驗證工程齒形、裝配公差或實際性能，不是可直接列印運作的製作套件。動畫僅示意傳動與方向，不是風速、扭力或車速模擬。

網站使用 Three.js 0.180.0，採 MIT 授權，授權文件位於 `assets/THREE-LICENSE.txt`。
